How Alerts Work

Database Triggers Generate Alerts

Alerts are not created by the frontend. Instead, database triggers automatically detect risk conditions (e.g., material stock below threshold, task delays, cost overruns) and insert records into the Alert table. This ensures alerts are data-driven and reliable.

Alert Types

  • material_low: Material inventory falls below safety threshold
  • cost_overrun: Project cost exceeds allocated budget
  • task_delay: Task completion date is overdue
  • schedule_conflict: Resource allocation conflict detected

Frontend Responsibilities

The frontend fetches alerts from the Alert table via REST API, displays them to engineers, and allows resolution status updates. The frontend does NOT generate alerts—it only consumes and displays them.
